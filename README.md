# W\*LDC\*RDZ
An optimization mod for [Word Play](https://store.steampowered.com/app/3586660/Word_Play/).
## What?
Makes word matching for `*` tiles and the `S=Z` modifier faster.
## How?
Instead of a linear search using regular expressions, a radix tree is used.
## Why?
I was bored and noticed a little stutter with submitting wildcard tiles.
